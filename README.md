# 论文降AI味 Skill 📝

> ⚠️ **强约束Skill：所有论文写作场景必须启用！**

## 📌 简介

这是一个**论文写作强约束**工具。无论你是在撰写、润色、修改、扩写还是缩写论文，只要涉及论文内容，这个Skill就会自动激活，强制检查并修正以下六类AI味问题。

## 🚨 重要特性

| 特性 | 说明 |
|------|------|
| 🔴 **强制激活** | 只要涉及论文写作，此Skill必须启用 |
| 🚫 **禁止绕过** | 不允许以任何理由保留问题句式 |
| ✅ **自动修正** | 主动识别问题并修改后再输出 |
| 📝 **保持语义** | 修改时不改变原意，只改变表达 |

## 🎯 六类必查问题

| 序号 | 问题类型 | 典型特征 | 优先级 |
|:----:|----------|----------|:------:|
| 1️⃣ | "了"的滥用 | `研究了b`、`分析了a` | ⚠️ 高 |
| 2️⃣ | "的"特定句式重复 | `a的b与c` | 🚨 最高 |
| 3️⃣ | 前缀形容词堆砌 | 大量`X的Y的Z` | ⚠️ 高 |
| 4️⃣ | "在xxx中"重复 | 同段落多次出现 | 🔄 中 |
| 5️⃣ | 口语化/赘述 | 超25字、口头禅 | 📏 中 |
| 6️⃣ | 句式雷同 | 对偶/排比结构 | ⚡ 高 |

## 🔧 核心原则

> ### 句式变换 > 同义词替换
> 
> 不要用同义词来"作弊"，要真正改变句式结构！

## 🚀 使用方法

当你进行任何论文相关操作时，SOLO会自动：
1. 检查输出是否触发六类问题
2. 发现问题立即修正
3. 以"人类"风格输出
