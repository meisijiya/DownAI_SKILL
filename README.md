# 论文降AI味 Skill 📝

> 降低论文AI率的六步排查法，让你的论文更"人类"！

## 📌 简介

这是一个帮助降低论文AI率（降低AIGC检测）的辅助工具。当你的论文需要避免被检测系统误判为AI生成时，可以使用这个Skill进行自我排查和修改。

## 🎯 适用场景

- 📄 论文写作完成后，降低AI生成率
- 🔍 提交AIGC检测前的自我排查
- ✍️ 修改论文中的人机感表达
- 📚 毕业论文、期刊论文、课程论文等

## 🔧 核心功能

### 六步排查法

| 步骤 | 排查内容 | 难度 |
|:----:|----------|:----:|
| 1️⃣ | "了"的使用规范 | ⭐ |
| 2️⃣ | "的"的特定句式滥用 | ⭐⭐ |
| 3️⃣ | 前缀形容词+的 | ⭐⭐ |
| 4️⃣ | "在xxx中"重复使用 | ⭐ |
| 5️⃣ | 口语化与赘述 | ⭐⭐⭐ |
| 6️⃣ | 句式雷同（对偶/排比） | ⭐⭐ |

## 🚀 使用方法

1. 将论文文本发送给 SOLO
2. 说明"帮我用降AI味的方式改一下"
3. SOLO 将根据六步法帮你修改

## ⚠️ 检测平台差异

| 平台 | 严格程度 | 建议 |
|------|:--------:|------|
| 知网 | 较宽松 | 常规修改即可 |
| 维普 | 较严格 | 需要更注重句式变化 |

## 💡 核心原则

> **句式变换 > 同义词替换**
> 
> 避免重复表达，同一句式不要反复使用
